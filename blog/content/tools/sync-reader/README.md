# Sync Reader

Sync Reader is a parallel text reader for learning German with Russian translations. It helps you read bilingual texts side by side, check words in context, save useful words while reading, and export them for Anki.

Try it here: [Sync Reader live demo](https://asavchenkodev.github.io/tools/sync-reader/index.html)


The main idea is to see a word immediately in sentence context instead of only having a direct word translation. You can also read the text first in your native language and then in the language you are learning, which makes the target-language text easier to understand.

I wanted the app to stay serverless, without accounts, subscriptions, or paid usage limits. Texts can be generated by the user with Claude, ChatGPT, Gemini, or another LLM using the app's specific prompt, then imported into Sync Reader. All texts, folders, saved words, and study data are stored locally in the browser.


## Features

- Parallel Russian and German reading panes.
- Hover a word or phrase to highlight the linked translation in both texts.
- Hide either side while keeping words available for hover and study.
- Click words to save them for review.
- Anki-style study mode for saved words.
- Ready-to-use Anki TSV export.
- Local library with folders, rename, move, and delete actions.
- Locally stored texts, folders, saved words, and study history.
- Built-in grammar rules view for A1-B1 German basics.
- Import texts generated with Claude, ChatGPT, Gemini, or another LLM in a sentence-scoped JSON format.
- Validation script to check that generated texts have complete word mappings.

## Local Data

Sync Reader stores user data in browser local storage:

- library texts
- folders
- selected text
- saved word cards
- word history
- UI preferences

The in-app local data reset removes this data and restores the bundled initial state.
